Global Coastal Evolution Modelling

ShorelineS Climate Change Global Scale

Project Overview

This project aims to develop a unified planetary view of coastal evolution. By coupling long-term shoreline models with global climate and sea-level rise data, we are working toward simulating how coastlines will change over the next century.
